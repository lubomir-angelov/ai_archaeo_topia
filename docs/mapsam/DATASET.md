# MapSAM v0 Dataset

## Overview

Dataset for fine-tuning the SAM (Segment Anything Model) mask decoder to segment
archaeological mound symbols on historical map imagery. Source: manually annotated
mound polygons from historical topographic maps, converted to binary masks with
bbox and center-point prompts per mound instance.

**Path:** `data/curated/datasets/mapsam_v0/`

Each mound annotation produces one training sample with:
- Binary target mask (single connected component)
- Bounding box prompt `[x_min, y_min, x_max, y_max]`
- Center point prompt `[cx, cy]`
- Ignore mask for uncertain regions

## Sample Generation

Generated by `src/archeo_topia/datasets/generate_mapsam_prompts.py`:

1. Load binary mound mask per image
2. Extract connected components
3. Skip components with area < `min_component_area` (20 px)
4. For each component: compute bbox (with 4 px padding) and center point
5. Write `training_samples.jsonl` with one row per component

Manifest: `data/curated/datasets/mapsam_v0/metadata/training_samples.jsonl`

## Training Configuration

Primary experiment: `mapsam_v0_1_decoder_only`

| Setting | Value |
|---------|-------|
| Model | SAM ViT-B (`sam_vit_b_01ec64.pth`) |
| Frozen | Image encoder, prompt encoder |
| Trainable | Mask decoder only |
| Input size | 1024x1024 |
| Image resize | bilinear |
| Mask resize | nearest |
| Batch size | 1 |
| Epochs | 50 (config) / 10 (completed) |
| LR | 1e-4 (AdamW, weight decay 0.01) |
| Loss | BCE (0.5) + Dice (2.0) |
| FG BCE pos-weight | 20x |
| Bbox loss crop | 32 px margin |
| Cached embeddings | yes |
| Seed | 42 |

Overfit-debug experiment: 5 samples repeated 200x (1000 effective), 200 epochs.

## Limitations

- Small dataset: 137 training samples across only 2 sheets
- Extreme class imbalance: mound symbols occupy ~0.05% of image pixels
- Single test sheet limits generalization assessment
- No data augmentation applied
- Frozen image encoder may limit decoder expressiveness on domain-specific features
